# Home page

Use the [!UICONTROL Home] page in [!DNL Adobe Marketo Optimizer] to start AI conversations, launch skills, and open marketing workspaces. Select **[!UICONTROL Home]** in the navigation to return to this page.

The personalized welcome message asks about your current tasks. Choose how to begin with the conversation input, intent options, quick access cards, or skill cards.

Watch the video for a tour of the home page and marketing workspace. The following sections provide written instructions.

>[!VIDEO](https://video.tv.adobe.com/v/3505360/?quality=12&learn=on)

## Start an AI conversation

Use the [!UICONTROL Ask a question or start a task] input to begin working with [!UICONTROL Coworker]. Enter `/` to browse skills and commands.

1. Enter a question or describe the task you want to complete.
1. To provide supporting material, select **[!UICONTROL Attach]** in the input and attach a file.
1. Submit your prompt to continue in the [!UICONTROL Coworker] panel.

The home page also provides four intent options for starting your work.

| Option | Goal |
| -------- | ------ |
| [!UICONTROL Plan] | Plan marketing activities. |
| [!UICONTROL Create] | Create marketing content or resources. |
| [!UICONTROL Measure] | Review marketing performance. |
| [!UICONTROL Optimize] | Refine existing marketing activities. |

For more information, read about the [chat interface](/help/user-guide/agents/chat-interface.md).

## Quick access

Select a [!UICONTROL Quick access] card to open a workspace or review AI decisioning health.

| Card | What you can access |
| ------ | --------------------- |
| [AI-decisioning health](/help/user-guide/agents/ai-decisioning-health.md) | Story volume and the percentage of people classified by persona. |
| [Marketing](/help/user-guide/marketing/marketing-management.md) | Programs, person journeys, and people lists in the marketing workspace. |
| [!UICONTROL Assets] | Content assets for emails and pages. |
| [!UICONTROL Reports] | Performance and engagement reports. |

## Skills

Select a card in [!UICONTROL Skills] to begin a specific AI workflow.

| Skill | Goal |
| ------- | ------ |
| [!UICONTROL Create persona-based audiences] | Generate audiences using persona signals and firmographic fit. |
| [!UICONTROL Build omni-channel programs] | Compose programs across email, web, and destinations from a brief. |
| [!UICONTROL Create hyper-personalized emails] | Draft personalized emails with tokens and dynamic content blocks. |
| [!UICONTROL Fit and intent-based journey traffic control] | Route contacts across journeys using account fit and intent signals. |

You can also browse agent skills from [!UICONTROL Coworker]. The video shows the [!UICONTROL Use an agent skill] dialog, with a search field and category filters. For details, read about [agent skills](/help/user-guide/agents/skills.md).

Use the application navigation to open the following work areas from the home page or marketing workspace.

| Work area | What you can access |
| ----------- | --------------------- |
| [!UICONTROL Marketing management] | Programs, person journeys, and people lists. |
| [!UICONTROL Journey traffic control] | [Journey traffic control](/help/user-guide/marketing/journey-traffic-control.md). |
| [!UICONTROL Reports] | Marketing performance reports. |
| [!UICONTROL Content management] | [!UICONTROL Templates], [!UICONTROL Assets], [!UICONTROL Fragments], [!UICONTROL Forms], [!UICONTROL Landing pages], and [!UICONTROL Webinar]. |
| [!UICONTROL Connections] | [Destinations](/help/user-guide/audiences/destinations.md). |
| [!UICONTROL Labs] | [Scoring Studio](/help/user-guide/labs/scoring-studio.md). |
| [!UICONTROL Administration] | [!UICONTROL Channels] and [!UICONTROL Program types]. |

## Explore the marketing workspace

Select the **[!UICONTROL Marketing]** quick access card or **[!UICONTROL Marketing management]** in the navigation to open the marketing workspace. Work with [!UICONTROL Coworker], open marketing resources, and return to recently accessed items without returning to the home page.

1. Select **[!UICONTROL Programs]**, **[!UICONTROL Person journeys]**, or **[!UICONTROL People lists]** in the **[!UICONTROL Marketing]** panel to browse resources.
1. Select a resource to open it in a workspace tab. Alternatively, select an item in **[!UICONTROL Recently accessed]**.
1. To continue working with different resources, switch between open tabs.

The [!UICONTROL Coworker] panel reflects the resource you open. Its prompts can target a selected program, people list, or person. For example, opening a person record provides prompts for exploring that person's persona and engagement activity.

Select **[!UICONTROL Collapse]** to hide the [!UICONTROL Coworker] panel or **[!UICONTROL Swap panels]** to change its placement. For more information, read about [marketing management](/help/user-guide/marketing/marketing-management.md) and [person details](/help/user-guide/audiences/person-details.md).
