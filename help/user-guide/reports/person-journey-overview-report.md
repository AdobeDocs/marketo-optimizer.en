# Person Journey Overview report

Use the [!UICONTROL Person Journey Overview] report to see the number of active person journeys across your instance for a selected date range.

_To view the report:_

1. In the left navigation, select **[!UICONTROL Reports]**.
1. Click the _List_ icon ( ![List icon](../assets/do-not-localize/icon-table-of-contents.svg) ) and select **[!UICONTROL Person Journey Overview]** in the _[!UICONTROL Table of contents]_ panel.

![Person Journey Overview report showing a tile with the number of active journeys and a Last 30 days date range.](./assets/reports-person-journey-overview.png){width="700" zoomable="yes"}

You can [change the date range](./reports-overview.md#change-the-date-range) for the report.

Select **[!UICONTROL Share]** at the top of the report to download or schedule an export of all report data. See [_Export a report_](./reports-overview.md#export-a-report) in the Reports overview.
